# Unfollow Radar
- `src/` kaynak, `unfollow-radar.js` üretilmiş tek dosyadır; elle düzenleme, `npm run build` ile üret.
- Veriyi tarayıcı dışına gönderme; ağ isteği, analitik veya CDN ekleme. Instagram otomasyon riskini ve yerel veri sınırını koru.
- Kontrol: `node --check unfollow-radar.js && node scripts/build.js --check`.
- `main` push'u GitHub Pages'i yayınlar.
